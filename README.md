# Lumenstru AI – High-Fidelity Prototype

Clickable high-fidelity prototype of **Lumenstru AI**, a phase-aware study planner for Android
(CS6008 Capstone Project). It shows the app inside a phone frame, with a navigator on the left
to jump to any screen and a switch between Matcha (light) and Lavender (dark) mode.

Built with plain HTML, CSS and JavaScript in one file (`index.html`). No framework and nothing to install.

## Screens
Sign In, Dashboard, Calendar, Log Period, Tasks, Add Task, Calm Space, AI Assistant,
Reminders (Survival Suite), Profile and App Settings. The features follow the September 2026
high-fidelity design; the look uses the final Matcha/Lavender design system.

## Run it
Open `index.html` in a browser, or use the live link.

## Notes
- All data is example data made relative to today's date.
- Logging a new period switches to Lavender Mode; ending it switches back to Matcha Mode.
- Only the chosen mode is saved in your browser.
- Fonts (Lora, DM Sans), the mascot pictures and the three calm tracks (royalty-free, Pixabay) are in `assets/`.
- The real app is a separate Android (Kotlin) project.
